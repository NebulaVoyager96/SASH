# SASH
Code for the paper "Structure-Aware Approximate Hypergraph Motif Counting for Higher-Order Interaction Analysis".

The real-world datasets can be obtained from https://www.cs.cornell.edu/~arb/data/.

To compile SASH, type:

g++ -O3 -std=c++11 main_approx_ver21.cpp -o approx_ver21

To run SASH, type:

./approx_ver21 10000
